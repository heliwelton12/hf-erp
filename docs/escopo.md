# HF ERP

Sistema para gerenciamento de papelaria, informática, impressão, acessórios e serviços.

## Objetivo

Criar um sistema próprio para uma loja física que trabalhe com papelaria, serviços de informática, impressão, personalizados e acessórios.

## Primeiro MVP

O primeiro módulo do sistema será Ordem de Serviço de Informática.

## Funcionalidades iniciais

- Cadastrar clientes
- Criar ordem de serviço
- Gerar número da OS
- Atualizar status da OS
- Consultar OS pelo número
- Listar ordens em aberto

## Status da Ordem de Serviço

- Recebido
- Em análise
- Em andamento
- Aguardando cliente
- Aguardando peça
- Concluído
- Entregue
- Cancelado

## Dados do Cliente

- ID
- Nome
- Telefone
- E-mail
- Data de cadastro

## Dados da Ordem de Serviço

- ID
- Número da OS
- Cliente
- Equipamento
- Marca/modelo
- Defeito relatado
- Serviço solicitado
- Status
- Valor
- Prazo de entrega
- Observações
- Data de abertura
- Última atualização
